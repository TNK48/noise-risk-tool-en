⚠️ Disclaimer: This tool is intended as a screening aid for occupational noise and is not a medical diagnosis. Risk values are relative estimates and do not substitute for formal health examinations. No input data is transmitted to or stored on any server (fully client-side). Always consult a qualified occupational physician or industrial hygienist before making decisions based on this tool.

Algorithm basis: Real-time & Data Input — ISO 1999:2013 §6.2 / OSHA 29 CFR 1910.95 (3 dB exchange rate). Forecast (NIPTS)— ISO 1999:2013 §6.3 Table 1(median). Note: may underestimate by 7–14 dB (Zhang 2022; BMC PH 2023). Forecast (ARHL)— ISO 1999:2013 Annex A discrete table (ISO 7029:2000 basis), linear interpolation. Provisional Ver. C. To be refined after obtaining ISO 7029:2017/Amd1:2024 official coefficients. Dementia risk — Livingston et al. (2020) Lancet 396, 413–446.
